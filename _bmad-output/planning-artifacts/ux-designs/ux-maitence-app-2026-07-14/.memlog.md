- (decision) Sources confirmed: prd.md, addendum.md, docs/Property_Trades_Taxonomy.md. Working mode: Fast path.
- (decision) Visual direction: fun, welcoming, confident -- engaged with an easy UI that doesn't overwhelm the user. User's own words, not a preset archetype.
- (decision) One shared visual identity across both surfaces (homeowner app + contractor dashboard), not two distinct tonal treatments.
- (decision) Platforms confirmed: Homeowner-facing = native mobile (iOS/Swift, Android/Kotlin). Contractor/Admin-facing = responsive web dashboard (Angular), used on both desktop and phone browser.
- (event) Initial full draft of DESIGN.md and EXPERIENCE.md written from PRD/addendum/taxonomy sources plus user's visual-direction decisions. DESIGN.md: coral primary (CTAs), teal trust (verification/confidence only), emergency red (Emergency Work Type only), Plus Jakarta Sans display + Inter body, rounded/pill shapes. EXPERIENCE.md: two-surface IA (native mobile homeowner app, responsive web contractor dashboard), Key Flows mirror PRD UJ-1 through UJ-4 verbatim.
- (decision) Contractor Trade/Service onboarding: search-first, Trade-scoped picker -- Contractor selects Trade(s) first from a short list, then searches/checks Services within each selected Trade. Avoids showing all ~20 Trades x all Services at once.
- (decision) Homeowner-facing no-match state (Cold Lead / FR-5 fallback categorization): honest, actionable message with a concrete next step (add detail, adjust budget) -- never silent, never a fake 'finding your contractor' spinner.
- (decision) Tier/Matching-Priority (FR-18) is a fully invisible ranking mechanic -- Contractor sees Tier only as an account/billing attribute (neutral Tier Badge), never a literal upgrade-to-rank-higher prompt. Protects the within-quality-band trust boundary from reading as a sales pitch.
- (decision) Non-Emergency Work Types (Repair, Maintenance, Improvement/Renovation, Inspection) get no dedicated badge -- conveyed via the existing Trade/Service text label on the Lead Card, not a color-coded chip. Deliberate: keeps the badge language reserved for genuinely urgent/trust signals (Emergency, Verified) per DESIGN.md's restrained-palette discipline.
- (event) Reviewer Gate ran: rubric walker (1 critical, 2 high, 4 medium, 3 low) + accessibility lens (independently confirmed the same critical contrast failure). Critical: primary/coral button system fails AA contrast in both directions (~2.82:1, needs 4.5:1). High: Verified Badge (~3.44:1) and Emergency Badge (~4.07:1) also fail/near-fail AA. High: Trade/Service Picker description contradicts PRD MVP scope (implies full ~20-Trade catalog, PRD scopes MVP to Phase-1 subset only). Fixing all before proceeding to key-screen mocks.
- (decision) Color fix: darkened primary #FF6B4A->#C2410C (~5.18:1 with white), trust #0F9B8E->#0B7A70 (~5.20:1), alert-emergency #E0483A->#C43A2E (~5.26:1). All computed against WCAG relative-luminance formula with margin above the 4.5:1 AA floor, not skating the edge.
